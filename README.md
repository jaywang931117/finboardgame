# 經濟棋局

一台電腦上輪流玩的多人財經桌遊。單頁遊玩可直接開啟 [index.html](./index.html)。

## 同一瀏覽器開多個頁籤

在本資料夾執行 `node serve.mjs`，然後在同一個瀏覽器的各頁籤開啟 **相同網址** `http://127.0.0.1:4173/`；也可按頁面右上角的「開啟同步頁籤」。所有頁籤會共用棋盤、回合、事件、玩家財務與總體數據；一個頁籤的操作會自動同步到其他頁籤。每個頁籤仍可停留在不同頁面，或查看不同季數的儀表板。操作前會檢查共同修訂版；瀏覽器支援 Web Locks 時也會序列化寫入，避免舊頁籤覆寫較新的回合。關閉執行 `node serve.mjs` 的終端機即可停止本機服務。

直接以 `file://` 開啟也可遊玩，但不同瀏覽器對本機檔案的儲存隔離方式不一致。要穩定共用對局，請使用上述本機網址。不同瀏覽器設定檔或無痕視窗不共用資料。

## 玩法

1. 選擇 2–8 位玩家與不同的企業角色，設定淨資產目標與季數上限。新對局會自動以開始時的時間戳記產生亂數種子。
2. 玩家輪流啟動兩個數字的拉霸。每個轉輪會停在 0–6，兩數相加為前進格數（0–12 格）；轉輪依序停定後，棋子以每秒一格的速度移動，走過的格子會留下螢光外框。總和 0 時停留原地，不抽新卡。幽靈每回合會隨機移動；若玩家走到幽靈格，剩餘步數作廢；該玩家本季收入歸零、支出照付，這回合不能抽卡或經營。棋盤交替出現全球、個人與產業事件格；停在事件格時，點擊棋盤中央流動的卡背才會抽卡並翻開事件。
3. 翻開事件卡後按「繼續經營」，棋盤中央會改為該企業的經營提示與本季預估。玩家可聘僱或裁員、借款或還款。銀行玩家可認列與收回壞帳。
4. 全部玩家完成行動後結算一季。事件影響先套用至十家企業，再建立總體經濟快照，最後由 AI 聯準會依 F01–F10 判斷下一季政策。若新一季有政策調整，棋盤中央會顯示跑馬燈快報，直到玩家啟動拉霸。
5. 有玩家破產、達成淨資產目標，或到達季數上限時結束。

全球事件影響所有適用企業，包括沒有玩家選擇的企業；個人事件只影響抽卡玩家；產業事件影響該產業的所有企業。事件可重複抽到並疊加，同一指標的總變動幅度限制於 −60% 至 +100%。玩家面板顯示已計入事件的本季收入、成本、淨利、投資資產，以及每張事件的剩餘季數。

遊戲自動儲存在目前瀏覽器的 `localStorage`。可從頁面頂端匯出 JSON，或匯入先前的存檔。亂數種子由開始時間自動產生，玩家無須設定；存檔會保留種子與對局狀態。

每家企業初始現金 1,200、投資資產基準值 800。預設勝利目標為淨資產 5,500，最多 12 季；這些值可在開局時調整。

## 開發

- `data.js`：規格中的十種企業、十張全球事件卡、十條聯準會規則，以及擴充的個人與產業卡。
- `engine.js`：兩輪拉霸、回合、事件、現金流、資產、總體快照與政策引擎。
- `app.js`、`styles.css`、`index.html`：介面。
- `game.js`：供直接開啟 HTML 使用的合併腳本，由 `node build.mjs` 產生。
- `sync.js`：跨頁籤對局修訂版排序與同步判斷。
- `serve.mjs`：僅監聽本機 `127.0.0.1:4173` 的靜態檔案服務。
- `engine.test.js`：規則與回合測試。執行 `node --test`。

修改來源檔後，執行 `node build.mjs` 更新 `game.js`。

本遊戲的數字依據提供的 MVP 規格，僅供遊戲使用。借款增加現金及負債，存量風險會進入總體儀表板；額外借款另依未償餘額 × 政策年利率 ÷ 4 計算每季利息；角色原有的利息收支維持原規則。

## 經營與存檔修正

- 營業收入隨員工數相對於企業初始人數同比例變化，上限為原營收的 150%；事件效果另外套用。人力成本仍依實際人數計算。裁員須立即支付被裁員工一季基本薪資作為資遣費，現金不足時不執行。
- 緊急流動性融資同時增加流動資產與短期負債，融資額依 `(15% × 原短期負債 − 原流動資產) / 85%` 計算，確保融資後流動性為 15%。
- 匯入與自動載入會驗證玩家、企業、銀行、回合、事件與歷史紀錄。缺少幽靈欄位的舊版完整存檔仍可載入；無效的手動匯入不會取代原對局。

- 頁首「動畫：標準／快速」可隨時切換動畫速度，設定保存在目前瀏覽器；快速模式每格 0.1 秒，不影響拉霸結果與事件。
- 新增借款按季末未償餘額收息，還款立即降低本季利息預估；罷工期間仍須支付借款利息。

## 事件主題擴充

事件共 58 張（全球 22、個人 18、產業 18），依內容分成政策與法規、科技與資安、氣候與能源、供應鏈與貿易、市場與消費、企業與人才六種主題。可在事件卡圖鑑篩選主題。每個產業有三張事件，以相同機率隨機抽取；影響範圍、季數衰減與疊加上限維持原規則。既有事件編號保留，舊存檔可繼續使用。
